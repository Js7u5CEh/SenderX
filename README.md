# TeleSender

📨 **TeleSender** — это утилита для рассылки персонализированных сообщений в Telegram с поддержкой нескольких аккаунтов и защитой от временных блокировок.

---

## 🚀 Возможности

- Рассылка сообщений по списку `t.me/username`
- Поддержка нескольких Telegram-аккаунтов с автоматической ротацией
- Ввод сообщения при запуске (с шаблонами `<МоёИмя>` и `<ЕгоИмя>`)
- Весомые задержки между отправками
- Простая конфигурация через текстовый файл (`config.txt`)
- Автоматическая авторизация аккаунтов при первом запуске

---

## 📁 Структура файлов

```
config.txt           # Настройки отправителей
recipients.csv       # Список получателей
main.py              # Точка входа (рассылка)
config_loader.py     # Загрузка отправителей
csv_loader.py        # Загрузка получателей
auth_manager.py      # Авторизация через Telethon
sender.py            # Отправка сообщений с шаблонами
```

---

## 🧾 Формат `config.txt`

Каждая строка — это Telegram-аккаунт:

```
session_name=sender1;api_id=123456;api_hash=abcdef123456abcdef123456abcdef12;my_name=Александр
```

---

## 📄 Формат `recipients.csv`

```
recipient
t.me/username1
t.me/username2
```

---

## 💬 Использование шаблонов

В тексте сообщения можно использовать:
- `<МоёИмя>` — заменяется на имя отправителя из `config.txt`
- `<ЕгоИмя>` — заменяется на имя получателя из Telegram

Пример:
```
Привет, <ЕгоИмя>! Я <МоёИмя>, хотел бы предложить вам сотрудничество.
```

---

## ⚙️ Запуск

```bash
python main.py
```

Программа:
1. Авторизует аккаунты (однократно)
2. Загружает получателей
3. Запрашивает текст сообщения
4. Выполняет рассылку с задержками и ротацией аккаунтов

---

## 🔐 Требования

- Python 3.10+
- `telethon` (`pip install telethon`)

---

## 📦 Автоматизация

Проект можно упаковать в `.exe` с помощью `pyinstaller`:
```bash
pyinstaller --onefile main.py
```

---

## 🛡️ Ограничения

- Нельзя отправлять сообщение самому себе
- Уважайте лимиты Telegram, чтобы избежать блокировок
